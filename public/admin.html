          trình duyệt khác — rồi đăng nhập tài khoản user; mỗi cửa sổ một phiên riêng nên test được cả 2 tính năng

          đổi được, trừ khi nó là admin hoạt động duy nhất (khi đó lấy lại quyền bằng

Khoá chỉ hiện MỘT lần. Chép nội dung dưới vào file agent\agent.config.json trên máy phụ (sửa threads và danh sách profile cho đúng máy đó). Mất khoá thì bấm "Đổi khoá".

        
        

      

    

  


  

    
Máy chủ

    

      

         Đang kiểm tra…
        
          
          
        
      

      

      

      

        Code mới = server khởi động sau lần sửa file cuối. Code cũ = có file mã nguồn (.mjs / .env) sửa sau khi server bật — cần khởi động lại để dùng bản mới.
        File giao diện (HTML/CSS/JS trong public/) luôn là bản mới nhất, chỉ cần Ctrl+F5.

        Khởi động lại sẽ huỷ các lượt đang chạy dở (không tính tiền) rồi tự chạy tiếp chiến dịch đang bật sau vài giây; trang tự tải lại khi server lên.
      

      

    


    

      
Mật khẩu truy cập từ ngoài (tunnel)

      

         Đang kiểm tra…
      

      

        

        

          
          
        

        

          
          
        

      

      

        
        
      

      

        Khách vào qua tunnel / tên miền phải nhập mật khẩu này trước khi thấy bất kỳ trang nào (kể cả trang đăng nhập); nhập đúng thì dùng được 12 giờ.
        Truy cập trực tiếp trên máy RDP (localhost:3300) không bị hỏi.

        Đổi mật khẩu = mọi khách phải nhập lại. Bật cổng mà chưa đặt mật khẩu thì khách bên ngoài bị chặn hoàn toàn.
        Mật khẩu chỉ gửi cho khách bằng kênh riêng (tin nhắn); hệ thống chỉ lưu bản băm, không xem lại được.
        Khi đã có tên miền chính thức và không cần cổng này nữa, bỏ chọn ô bật rồi lưu.
